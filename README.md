## What is Liberide?

Liberide is a fully open-source coding agent that brings AI assistance directly into your development workflow.

> **Note:** This project is an independent fork of [Continue](https://github.com/continuedev/continue), which is no longer actively maintained. Liberide continues the mission under the **GNU General Public License v3**, ensuring the codebase remains completely free and open for the community.

---

## Project Status

Liberide is currently in a **refactoring and rebranding stage**.

We are actively working on:
- Rebranding the codebase from Continue to Liberide
- Updating documentation and build pipelines
- Cleaning up dependencies and legacy code
- Preparing the project for public contributions

> **The project is not yet ready for end users.** Significant work is required before extensions and plugins can be built and distributed. We appreciate your patience and will announce updates as milestones are reached.
