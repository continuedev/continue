---
title: "How to Run Continuous Without Internet"
description: "Learn how to set up Continuous for air-gapped or offline environments using local models, including how to configure local model providers. Continuous sends no telemetry."
---

1. Download the latest .vsix file from the [GitHub Releases page](https://github.com/b1tninja/continuous/releases) and [install it to VS Code](https://code.visualstudio.com/docs/editor/extension-marketplace#_install-from-a-vsix).
2. In your `config.yaml` file (or through the Continuous UI), set the default model to a local model. You can find available local model options [here](../customize/model-providers/top-level/ollama.mdx).
3. Restart VS Code to ensure that the changes to `config.yaml` take effect.
