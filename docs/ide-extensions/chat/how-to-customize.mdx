## How to Customize Chat

There are a number of different ways to customize Chat:

- Add [rules](../../customize/rules.mdx) to give the model persistent instructions through the system prompt
- Create [prompts](../../customize/prompts.mdx) to kickoff workflows with instructions you repeat often
