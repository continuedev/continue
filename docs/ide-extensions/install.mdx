---
title: "Install"
description: "Install Continued in VS Code from a .vsix build."
---

Continued is installed from a `.vsix` file; it is not on the VS Code Marketplace or Open VSX.
The full instructions, with checksums and troubleshooting, are in the
[install guide](https://github.com/b1tninja/continued/blob/main/docs/continued-install.md).

<Steps>
<Step title="Download the build for your platform">
`continued-win32-x64`, `continued-darwin-arm64` (Apple Silicon), `continued-darwin-x64` (Intel Mac) or `continued-linux-x64`.
</Step>

<Step title="Install it in VS Code">
Run `code --install-extension continued-<platform>-<version>.vsix --force`, or use the Extensions view: `...` menu → **Install from VSIX…**. Then reload the window.
</Step>

<Step title="Move to the right sidebar (optional)">
The Continued icon appears in the Activity Bar on the left. To keep Chat from covering the file explorer, right-click the icon and choose **Move To** → **Secondary Side Bar**.
</Step>
</Steps>

<Info>
  If you have any problems, see the [troubleshooting guide](../troubleshooting.mdx).
</Info>
