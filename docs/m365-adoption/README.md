M365 Adoption — Plan y artefactos

Este directorio contiene el plan de adopción de Microsoft 365 / Teams para la organización, plantillas, flujos de Power Automate de ejemplo y métricas para seguimiento.

Contenido:
- teams-structure.md — Recomendaciones de estructura de Teams (equipos, canales, plantillas)
- onboarding-checklist.md — Checklist de onboarding para nuevos equipos/miembros
- training-schedule.md — Propuesta de programa de formación
- power-automate-samples.md — Descripción de flujos de ejemplo y enlaces a definiciones JSON
- flows/notify-on-new-doc.flow.json — Flujo: Notificar en Teams cuando se agrega un documento a SharePoint
- flows/escalate-issue.flow.json — Flujo: Escalar un issue por inactividad/estado
- adoption-kpis.md — KPI recomendados para adopción y definición
- powerbi-dashboard-template.md — Plantilla y guía para dashboard de Power BI

Por favor revise y adapte los artefactos a las políticas y governance de su organización.
