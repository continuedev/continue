description: "Open-source AI code agent for VS Code"

**Continued is an open-source AI code agent for VS Code: agent, chat, edit and autocomplete, with the models you choose.** It is a community-maintained fork and is not affiliated with Continue Dev, Inc.

## Key Features

- [Agent mode](./ide-extensions/agent/quick-start.mdx) to work on development tasks together with AI
- [Chat mode](./ide-extensions/chat/quick-start.mdx) to ask general questions and clarify code sections
- [Edit mode](./ide-extensions/edit/quick-start.mdx) to modify code sections without leaving your current file
- [Autocomplete](./ide-extensions/autocomplete/quick-start.mdx) to receive inline code suggestions as you type

Install it from a `.vsix` build: see the [install guide](https://github.com/b1tninja/continued/blob/main/docs/continued-install.md).
