## What is Continued?

**Continued is an open-source AI code agent for VS Code.** It is a community-maintained fork and is not affiliated with Continue Dev, Inc.

## Key Features

1. Install Continued from the [latest release](https://github.com/b1tninja/continued/releases/latest): see the [install guide](https://github.com/b1tninja/continued/blob/main/docs/continued-install.md). Then:
- [Agent mode](./ide-extensions/agent/quick-start.mdx) to work on development tasks together with AI
- [Chat mode](./ide-extensions/chat/quick-start.mdx) to ask general questions and clarify code sections
- [Edit mode](./ide-extensions/edit/quick-start.mdx) to modify code section without leaving your current file
- [Autocomplete](./ide-extensions/autocomplete/quick-start.mdx) to receive inline code suggestions as you type

2. Report problems and ideas at [github.com/b1tninja/continued](https://github.com/b1tninja/continued/issues).
