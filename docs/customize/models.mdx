## Learn More About Models

Continuous supports [many model providers](./model-providers/top-level/openai.mdx), including Anthropic, OpenAI, Gemini, Ollama, Amazon Bedrock, Azure, xAI, and more. Models can have various roles like `chat`, `edit`, `apply`, `autocomplete`, `embed`, and `rerank`.

To add a provider, choose its models and store the API key, use the [setup flow](./model-setup.mdx). Read more about [model roles](./model-roles.mdx), [model capabilities](./deep-dives/model-capabilities.mdx) and view [`models`](../reference.mdx#models) in the YAML Reference.

Claude Sonnet 4.6 from Anthropic

1. Get your API key from [Anthropic](https://console.anthropic.com/)
2. Add Claude Sonnet 4.6 to your Continuous config
3. Add `ANTHROPIC_API_KEY` to your environment or config
