Continuous can be deeply customized to fit your specific development workflow and preferences. This guide covers the main ways you can customize Continuous to enhance your coding experience.

## Change Your Model Provider

Continuous allows you to choose your favorite or even add multiple model providers. This allows you to use different models for different tasks, or to try another model if you're not happy with the results from your current model. Continuous supports all of the popular model providers, including OpenAI, Anthropic, Microsoft/Azure, Mistral, and more. You can even self host your own model provider if you'd like.

[Learn more about model providers →](./model-providers/overview.mdx)

## Select Different Models for Specific Tasks

Different Continuous features can use different models. We call these _model roles_. For example, you can use a different model for Chat mode than you do for Autocomplete.

[Learn more about model roles →](./model-roles.mdx)

## Edit Your Configuration

You can easily access your configuration from the Continuous Chat sidebar. Open the sidebar by pressing `cmd/ctrl` + `L` (VS Code) and click the Agent selector above the main chat input. Then, you can hover over an agent and click the `gear` icon.
