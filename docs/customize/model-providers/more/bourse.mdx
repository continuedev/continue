<Info>
  Bourse provides access to models through an OpenAI-compatible API. Get an API
  key and review the available models and pricing at [bourse.run](https://bourse.run).
</Info>

## Configuration

Add a model with the `openai` provider and set `apiBase` to the Bourse API
endpoint:

```yaml title="config.yaml"
name: My Config
version: 0.0.1
schema: v1

models:
  - name: Claude Opus 5 (Bourse)
    provider: openai
    model: claude-opus-5
    apiBase: https://api.bourse.run/v1
    apiKey: <YOUR_BOURSE_API_KEY>
```

Replace `claude-opus-5` with the model identifier listed in the Bourse
catalogue when selecting another model.
