# Contributing to Please Continue

Thank you for helping make Please Continue clearer, safer, and more dependable.

> **Contribution status**
>
> External pull-request intake is not yet open. Fork-owned contributor terms,
> security contacts, and review rules are being finalized. Please do not begin
> a substantial code change until the relevant contribution path is announced.

Please Continue is an early-stage community-maintained fork. Contributions
should deliver one coherent, independently useful outcome rather than unfinished
scaffolding or broad speculative refactoring.
