## Candidate dossier trigger

Do not create implementation branches from this table. A cluster becomes a
candidate only when an authorized maintainer records:

- the selected supported outcome;
- current reproduction or deterministic substitute;
- exact source base;
- affected surfaces and non-goals;
- executable acceptance checks;
- security and privacy classification;
- linked issue/PR state and provenance;
- independent/adapted/synchronized implementation mode; and
- an owner and review path.
