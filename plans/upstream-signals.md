# Upstream signals

Last updated: 2026-11-03.

What the open issues and pull requests of `continuedev/continue` say about bugs worth fixing and features people want. Collected on this date with `gh`. Each row says what was checked in this fork's code and what was not.

## Sources and limits

- Issues: three lists of 150 open issues (most reacted, most commented, newest), 287 unique. This is not a random sample: it favors old popular requests and the last four months.
- Pull requests: the 100 open and the 100 most recently merged.
- Reactions are small numbers except for requests for other editors, so a count shows a cluster, not a ranking.
- This fork has issues turned off, so there is no tracker of our own to add.
- Issue text is what users reported. "Verified" below means the code path was read here, not that the bug was reproduced.

## State of upstream

- The README is quoted in issue #12629 as saying the repository is no longer actively maintained. In June 2026 a maintainer said it would be archived after the final 2.0.0 release. At collection time it was not archived, and the reporter was still asking in October.
- The 100 most recent merged PRs run from 2026-03-21 to 2026-07-21, and nothing has merged since. Many of the 100 open PRs are Snyk dependency PRs opened under a maintainer account. The few feature and fix PRs opened here showed no or one review; the rest were not looked at.
- Issues are still arriving: the newest 150 open issues span 2026-07-01 to 2026-11-03.

Fixes will not come from upstream, but the open PRs are a pool of candidate patches by people who hit the same problems. Check the license and attribution rules before copying any code. Where possible, rewrite from the description with tests and credit the PR.
