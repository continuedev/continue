# Shadow Code

**AI code agent for JetBrains IDEs**

Shadow Code brings an AI coding agent into your IDE: chat about your codebase,
make multi-file edits, run an autonomous agent, and get inline autocomplete.

## Features

- **Chat** — ask questions about your code without leaving the IDE
- **Edit** — describe a change in natural language and apply it inline
- **Agent** — let the model plan and carry out larger tasks with tool access
- **Autocomplete** — inline single- and multi-line suggestions as you type

Configuration lives in `~/.shadow-code/config.yaml` and in a `.shadow-code/`
folder in your project.

Shadow Code is a fork of the Continue open-source project. Licensed under Apache-2.0.
